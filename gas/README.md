# การนำเว็บไซต์ห้อง ม.6/6 APE ขึ้นออนไลน์บน Google Apps Script

โฟลเดอร์ `gas/` นี้มีไฟล์ที่พร้อมนำไปวางบน **Google Apps Script** (`script.google.com`) ได้ทันที:

- `Code.gs` — ฝั่งเซิร์ฟเวอร์ Google Apps Script (ดึงข้อมูลคนติดมหาลัยจาก Canva อัตโนมัติ, นับสถิติผู้เข้าชม, และบันทึกโน้ต/คอมเม้นสมุดเยี่ยมใน PropertiesService)
- `Index.html` — หน้าเว็บ React + Tailwind CSS + รูปตารางเรียนต้นฉบับที่รวมเป็นไฟล์เดียวเรียบร้อยแล้ว
- `appsscript.json` — ตั้งค่า Timezone (`Asia/Bangkok`) และสิทธิ์เปิดใช้งาน Web App สาธารณะ

## วิธีเปิดเว็บออนไลน์บน Google Apps Script (แบบ Copy & Paste ง่ายที่สุด)

1. เปิด [https://script.google.com](https://script.google.com) แล้วกด **New project (โปรเจกต์ใหม่)**
2. ที่ไฟล์ `Code.gs` เดิม ให้ลบโค้ดเก่าทิ้งทั้งหมด แล้วคัดลอกโค้ดทั้งหมดจากไฟล์ `gas/Code.gs` มาวางแทนแล้วกดบันทึก (`Ctrl+S`)
3. กดปุ่ม `+` ข้างคำว่า **Files** เลือก **HTML** ตั้งชื่อไฟล์ว่า `Index` (ตัว `I` ใหญ่ — ระบบจะได้ `Index.html`)
4. ลบโค้ดตัวอย่างใน `Index.html` ออกทั้งหมด แล้วคัดลอกเนื้อหาทั้งหมดจากไฟล์ `gas/Index.html` มาวางแทนแล้วกดบันทึก
5. กดปุ่ม **Deploy (ทำให้ใช้งานได้)** มุมขวาบน > **New deployment (การทำให้ใช้งานได้รายการใหม่)**
6. กดรูปเฟืองเลือกประเภทเป็น **Web app (เว็บแอป)**
   - **Execute as (ดำเนินการในฐานะ)**: `Me` (บัญชีของคุณ)
   - **Who has access (ผู้ที่มีสิทธิ์เข้าถึง)**: `Anyone` (ทุกคน)
7. กด **Deploy** แล้วอนุญาตสิทธิ์ครั้งแรก (เลือก Advanced > Go to ... หากขึ้นเตือน) จากนั้นจะได้ลิงก์ `https://script.google.com/macros/s/.../exec` สำหรับแชร์ให้เพื่อนๆ ใช้งานได้ทันที!

## วิธีอัปเดต `gas/Index.html` หลังจากแก้ไขโค้ดเว็บ

รันคำสั่งนี้ในโปรเจกต์เพื่อสร้างไฟล์ `gas/Index.html` เวอร์ชันล่าสุดอัตโนมัติ:

```bash
npm run build:gas
```
